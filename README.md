# 🌐 Azure Network Protocol Setup

This repository documents and automates the setup of various **network protocols** within Azure environments. The goal is to deploy network infrastructure and secure protocols to ensure that applications and services running on Azure communicate securely and efficiently.

---

## 🛠️ Prerequisites

- Azure Subscription
- Azure CLI or PowerShell
- Basic knowledge of Azure networking and security concepts

---

## ⚙️ Setup Overview

1. **Create a Virtual Network (VNet)**  
2. **Configure Subnets and Network Security Groups (NSG)**  
3. **Set up DNS for Name Resolution**  
4. **Configure Inbound and Outbound Traffic Rules for Network Protocols**  
5. **Deploy VMs and Test Connectivity**
